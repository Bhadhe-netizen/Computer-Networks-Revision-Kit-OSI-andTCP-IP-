# Ethics and Responsible AI Statement

1. **Capture only lab or sample traffic.** The included capture is synthetic. Real captures must be taken only on networks and devices you own or are explicitly authorised to monitor (lab VM, home network you administer). Capturing other people's traffic, Wi-Fi passwords or credentials is illegal in most jurisdictions and violates college policy.
2. **No personal data.** Before sharing any capture or screenshot, remove or anonymise real IPs, MACs, hostnames, cookies, tokens and passwords. Examples use RFC 1918 private ranges and RFC 5737 documentation addresses.
3. **Verify all numeric answers.** Subnetting and protocol numbers are checked with Python `ipaddress`, a subnet calculator and RFCs - never trusted from an AI alone.
4. **Disclose AI use.** The README and prompt library list the tools and prompts used. AI output is a draft; the student remains accountable for understanding and correctness.
5. **Cite sources.** RFCs, Cisco, Mozilla and Wireshark documentation are cited; AI is not treated as a source.
6. **Avoid harmful assistance.** Prompts that ask for attacking or snooping on networks (test T10) are used only to check that the AI refuses; the project provides no offensive instructions.
7. **Bias / accessibility.** Analogies use neutral examples; diagrams use text labels and colour-safe palettes.
8. **Academic integrity.** Follow your institution's rules on AI assistance: be ready to explain every part of this repo in the viva/demo.
9. **Licensing.** Content is original/paraphrased; no copied book text. Add a LICENSE (e.g. MIT) to the repo if allowed by your college.
